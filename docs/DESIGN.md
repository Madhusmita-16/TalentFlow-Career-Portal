# 🎨 TalentFlow Design System & UI/UX Guidelines

## 🌈 Color Palette & Design Tokens
- **Primary / Brand**: Slate & Indigo (`#1e293b`, `#4f46e5`, `#6366f1`)
- **Accent / AI**: Purple & Cyan Gradient (`#8b5cf6` to `#06b6d4`)
- **Status Colors**:
  - Success / Hired: Emerald (`#10b981`)
  - Info / Reviewing: Blue (`#3b82f6`)
  - Warning / Interviewing: Amber (`#f59e0b`)
  - Danger / Rejected: Rose (`#f43f5e`)

## 📱 Responsive & Component Guidelines
- **Framework**: React 18 + Tailwind CSS v4 + Lucide React icons.
- **Theme Modes**: Dark Mode and Light Mode toggle support.
- **Interactions**: Smooth glassmorphism overlays, skeleton loaders, toast notifications, micro-animations, and full accessibility compliance.
